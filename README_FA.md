# IAU Sherlock - یک چت‌بات RAG

[🇬🇧 EN](README.md) | **🇮🇷 FA**

این پروژه، پروژه‌ی کارشناسی من با محوریت **Retrieval-Augmented Generation (RAG)** می‌باشد.

در این پروژه، یک چت‌بات RAG کامل پیاده‌سازی کرده‌ام.

## ویژگی‌ها

- پاسخگویی مبتنی بر RAG به سوالات مربوط به قوانین دانشگاه آزاد
- پشتیبانی از چندین زبان (با استفاده از مدل‌های چندزبانه‌ی Nvidia)
- ذخیره‌سازی برداری با Qdrant
- سرویس دریافت و پردازش اسناد
- قابلیت اجرا با داکر برای استقرار آسان
- مستندسازی API با Swagger
- نمونه‌ی فرانت‌اند برای تست
- نمونه‌ی اسنپ‌شات Qdrant برای تست

## شروع سریع

### پوشه‌ی کاری خود را ایجاد کرده و پروژه را clone کنید

```bash
mkdir IAU_RAG
cd IAU_RAG

git clone https://github.com/Niazi04/IAU_Sherlock.git .
```

### متغیرهای محیطی

پروژه از متغیرهای محیطی برای پیکربندی استفاده می‌کند. یک فایل `.env` در ریشه‌ی پروژه ایجاد کنید:

```bash
cp .env.example .env
```

حالا فایل `.env` را با اطلاعات اعتبارسنجی API خود ویرایش کنید. مهم‌ترین مقادیر عبارتند از:

```
LLM_API_URL=    # ارائه‌دهنده‌ی LLM شما. من از Nvidia استفاده کردم (رایگان است)
LLM_MODEL_NAME= # LLM - باید چندزبانه باشد. من از nvidia/nemotron-3-ultra-550b-a55b استفاده کردم
LLM_API_KEY=    # کلید API سرویس LLM
EMBEDDING_SERVICE_URL= # ارائه‌دهنده‌ی سرویس Embedding. من از Nvidia استفاده کردم (رایگان است)
NVIDIA_API_KEY= # کلید API سرویس Embedding. از مدل nvidia/nemotron-3-embed-1b استفاده کنید
UI_API_KEY=     # کلید X-API-KY سفارشی شما که توسط فرانت‌اند و تست Swagger استفاده می‌شود
```

می‌توانید مدل‌های ذکر شده را در build.nvidia.com/models بررسی کنید.

کلید API خود را دریافت کرده و ادامه دهید.

یک کلید API سفارشی قوی برای UI_API_KEY تنظیم کنید (فرانت‌اند و Swagger از این کلید استفاده می‌کنند).

### اجرای کانتینر داکر

```docker
docker compose -f 'docker-compose.dev.yml' up -d --build
```

**توجه:** مطمئن شوید که موتور داکر شما در حال اجرا است!

**توجه:** تصاویر و نیازمندی‌ها از یک آینه (mirror) استفاده خواهند کرد. اگر خارج از ایران هستید، می‌توانید با خیال راحت آینه‌ها را حذف کنید.

## راه‌اندازی Qdrant

داکر کار راه‌اندازی Qdrant را انجام می‌دهد. با این حال برای شروع و تست پروژه به چند نقطه‌ی نمونه (داده) نیاز دارید.

ابتدا باید داده‌ها را embedding کنید، سپس payload مناسب را به هر embedding متصل کنید و در نهایت کل مجموعه را در Qdrant بارگذاری (upsert) نمایید.

خوشبختانه، می‌توانید از نقطه‌ی پایانی `faq/mine/file` استفاده کنید که کل این فرآیند را به صورت خودکار انجام می‌دهد.

ابتدا به آدرس `http://localhost:8000/docs` بروید. سپس تنها کاری که باید انجام دهید این است که فایل داده‌ی موجود در `docs\data.json` را آپلود کنید. نام مناسبی برای مجموعه (collection) تعیین کنید و روی دکمه‌ی اجرا (execute) کلیک کنید.

پس از اتمام کار، به فایل `.env` خود بروید و `FAQ_COLLECTION_NAME` را به نامی که به مجموعه‌ی خود داده‌اید، به‌روزرسانی کنید.

کانتینر را مجدداً راه‌اندازی کنید و کار شما انجام شده است.

## تست برنامه

دو گزینه برای کار با پروژه دارید:

1. **Swagger**

    پس از ساخته شدن کانتینر، به آدرس http://localhost:8000/docs بروید.
    
    در آنجا تمام نقاط پایانی موجود را مشاهده می‌کنید و حتی می‌توانید فرانت‌اند مخصوص خود را برای این پروژه ایجاد کنید.

2. **نمونه‌ی فرانت‌اند من**

    در دایرکتوری پروژه به دنبال `sample_frontend` بگردید. در داخل فایل `js\config.js`، کلید UI_API_KEY خود را به این صورت وارد کنید:
    
    ```js
    apiKey: "کلید_API_شما"
    ```

    سپس فایل `index.html` را در مرورگر خود باز کنید. اکنون می‌توانید چت کرده و سوالات خود را در مورد قوانین دانشگاه آزاد بپرسید.

**توجه برای کاربران ایرانی:** برای اتصال به سرویس‌های NVIDIA باید از VPN استفاده کنید. اگر از ارائه‌دهنده‌ی دیگری استفاده می‌کنید که آی‌پی ایران را تحریم نکرده است، می‌توانید با خیال راحت VPN خود را خاموش کنید.

## سوالات متداول

1. چگونه می‌توانم داده‌های خود را در Qdrant آپلود کنم؟

   پاسخ: باید یک مجموعه داده‌ی json مشابه `docs\data.json` ایجاد کنید.

   پس از آماده شدن، به رابط Swagger رفته و داده‌های خود را از طریق نقطه‌ی پایانی `faq/mine/file` وارد کنید.

   سپس مطمئن شوید که فایل env خود را به‌روزرسانی کنید.

   سرور را مجدداً راه‌اندازی کنید و کار شما انجام شده است.

2. نمی‌توانم به رابط کاربری متصل شوم.
   
   پاسخ: احتمالاً این مشکل به دلیل عدم تطابق `UI_API_KEY` است. آن را بررسی کنید.

   - کلید موجود در `.env` با `sample_frontend/js/config.js` مطابقت داشته باشد.

   - ارائه‌دهنده‌ی API شما در دسترس باشد (سعی کنید نقطه‌ی پایانی را پینگ کنید).

   کانتینر در حال اجرا است:

   ```bash
   docker compose ps
   ```
